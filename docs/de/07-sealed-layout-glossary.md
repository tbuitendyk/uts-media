# Ein Begriff für die Prüfung einer Handelsregel: die versiegelte Anordnung (Training, Test, Zurückgehalten, Reserve)

_Vier Teile der Historie mit je einer Aufgabe, damit die Historie, die eine Handelsregel beurteilt, nie die ist, die sie ausgewählt hat._

Wer fragt, ob eine Handelsregel echt ist, muss als Nächstes fragen: echt auf welcher Historie? Eine versiegelte Anordnung beantwortet das, indem sie die Historie in vier Teile mit je einer Aufgabe teilt, bevor irgendetwas ausprobiert wird.

## Training

Die Historie, aus der die Suche lernt. Hier werden Regeln angepasst, also sieht eine Regel hier immer gut aus. Nichts, was im Training geschieht, zählt als Beleg.

## Test

Die Historie, auf der zwischen den gefundenen Regeln gewählt wird. Es ist nicht die Historie, auf der sie angepasst wurden, aber es ist Historie, auf der eine Wahl getroffen wurde. Sobald man die beste von vielen Regeln im Test auswählt, beginnt der Test, den Gewinner zu schönen.

## Zurückgehalten

Historie, die beiseitegelegt wurde, während alle Entscheidungen fielen. Die überlebenden Regeln werden hier beurteilt, gegen einfachere Arten, denselben Abschnitt zu handeln. Zurückgehalten ist die erste ehrliche Messung, aber nur einmal: Wer wegen ihres Ergebnisses etwas ändert, lässt auch sie mitwählen.

## Reserve

Ein letzter Abschnitt, der ganz zum Schluss geöffnet wird, wenn alles andere entschieden ist. Er ist der Teil, der noch ungesehen ist, wenn nichts mehr anzupassen bleibt. Eine Regel, die hier besteht, wurde auf Historie beurteilt, auf der nie eine Wahl getroffen wurde.

## Warum „versiegelt"

Weil die Teile festgelegt werden, bevor die Arbeit beginnt, und die späteren nicht vorher angesehen werden. Wer die Historie nur zweiteilt und den zweiten Teil mehr als einmal ansieht, wählt wieder auf der Historie, die ihn beurteilen sollte.
