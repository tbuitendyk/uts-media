# Ein Begriff für die Prüfung einer Handelsregel: das gepflanzte Muster

_Bevor Sie einer Suche trauen, die eine Regel gefunden haben will, prüfen Sie, ob sie eine findet, die Sie absichtlich versteckt haben. Was ein gepflanztes Muster ist und wie man es nutzt._

Jede Prüfung auf dieser Liste fragt, ob eine Regel echt ist. Diese fragt etwas Früheres: Kann die Suche überhaupt eine echte Regel finden?

## Was er bedeutet

Ein gepflanztes Muster ist eine Regel, die Sie absichtlich in einen erfundenen Markt legen. Sie bauen Preise, die einem bekannten Muster folgen, vermischt mit Rauschen, sodass Sie die richtige Antwort kennen, bevor Sie anfangen. Dann lassen Sie die ganze Suche über diesen Markt laufen, genau wie über echte Historie, und sehen nach, ob sie findet, was Sie versteckt haben.

## Warum er zählt

Eine Suche, die nie versagt, beweist nichts. Hat die Maschinerie einen Fehler, kann sie Regeln melden, die es nicht gibt, oder Regeln übersehen, die es gibt. Auf echter Historie lässt sich das nicht unterscheiden, weil niemand die richtige Antwort kennt. Auf einem erfundenen Markt schon. Eine Suche, die ein gepflanztes Muster nicht findet, verdient kein Vertrauen, wenn sie eines gefunden haben will, das niemand gepflanzt hat.

## Wie man ihn nutzt

Pflanzen Sie ein Muster, schicken Sie es durch die echte Kette, nicht durch eine Abkürzung, und prüfen Sie, ob es gefunden wird. Dann verwürfeln Sie denselben erfundenen Markt, sodass das Muster zerstört ist, lassen alles noch einmal laufen und prüfen, dass nichts gefunden wird. Beide Hälften zählen: Das Muster zu finden zeigt, dass die Suche sieht; bei den verwürfelten Kopien leer auszugehen zeigt, dass sie nichts sieht, was nicht da ist. Wiederholen Sie die Prüfung, wann immer sich die Software ändert.

## Wo er unter den anderen Prüfungen steht

Sie kommt zuerst, bevor irgendeine Regel beurteilt wird: erst das Instrument prüfen, dann der Messung trauen. Danach kommen, wie gut „nichts" aussieht, die Historie, die die Regel nie gesehen hat, und die einfacheren Arten, denselben Abschnitt zu handeln.
