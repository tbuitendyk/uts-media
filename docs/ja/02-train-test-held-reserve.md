# 学習、テスト、ホールド、リザーブ：一度見てしまうと、取り置きデータが一つでは足りなくなる理由

_取り置いたデータがルールを公平に判定できるのは、その結果を見て手を加えるまでです。履歴を四つに分け、最後の一つを一度だけ開く理由を説明します。_

過去の価格で取引ルールを試したことのある人は、最初の教訓をすぐに学びます。履歴のある区間に合わせて調整したルールは、その区間では良く見えます。そこに合うように形を整えたのですから当然です。そこで、履歴の一部を取り置き、残りで調整して、ルールが一度も見ていない部分で確かめます。この部分は、ふつうアウトオブサンプルのデータと呼ばれます。この記事では「取り置きデータ」と呼ぶことにします。

考え方としては正しいものです。ただ、たいていの人が思うより早くすり減ります。しかも、すり減らすのは、ごくまっとうな習慣です。結果を見て、それから何か手を打つ、という習慣です。

## 取り置きデータはこうして使い切られる

架空の例で考えます。履歴のある区間を探して、候補のルールが二十個見つかったとします。二十個すべてを取り置きデータで走らせます。ほとんどは振るいません。三つは良い成績です。その三つを残し、取り置きデータでの成績を根拠として書き留めます。

この成績は、もうきれいではありません。取り置きデータはルールを判定するはずでした。ところが実際には、ルールを選んでしまいました。そこで成績が良かったから残したのですから、そこで成績が良いのは当たり前です。

コインで考えるとはっきりします。二十人にコインを一枚ずつ渡し、それぞれ十回投げてもらいます。表が多かった三人を残します。三人の記録は立派に見えますが、どれもごく普通のコインだったとしても、同じように立派に見えます。いま感心しているまさにその点で選んだからです。同じ三人にもう一度投げてもらえば、ごく普通の結果に戻ります。

同じことは、もっと静かにも起こります。取り置きデータでの結果が期待外れだったので、戻ってセッティングを一つ変え、もう一度確かめます。少し良くなりました。もう一つ変えます。この往復の一回一回が、取り置きデータの助けを借りた小さな選択です。十分に繰り返せば、ルールは最初の区間に合わせ込まれたのと同じように、取り置きデータにも合わせ込まれます。時間が余計にかかっただけです。しかも、どの一歩にも不正はありません。

ここから出てくる原則は、言うのは簡単で、守るのは難しいものです。ルールを判定する履歴は、そのルールを選んだ履歴であってはならない、という原則です。履歴のある区間が選択に影響したとたん、その区間は立場を変えます。もう選ぶ側の一部です。

## 二つではなく四つに分ける

見ることと選ぶことが履歴をすり減らすのなら、答えは、どの履歴をすり減らしてよいかを先に決め、まったく使わない部分を残しておくことです。一つのやり方は、履歴を四つに分けます。学習、テスト、ホールド、リザーブです。

**学習**と**テスト**は作業用の部分です。ルールを見つけ、比べ、手直しし、捨てるのはここです。何度見てもかまいません。すり減るのは織り込み済みで、ここでの好成績に感心する必要はありません。

**ホールド**は、どの選択も一度も行われなかった履歴です。最初の二つを生き残ったルールは、ここで判定されます。この部分では何も選ばれず、何も手直しされていないので、ここでの成績には、作業用の部分での成績にはない意味があります。

**リザーブ**は最後に来ます。これがあるのは、先ほどの問題のためです。ホールドの結果を見てしまえば、あなたはもう「見た人」です。何かを手直ししたくなるかもしれません。あるいは、ホールドで一番良かったものだけを先へ進めたくなるかもしれません。それは二十枚のコインと同じ誤りです。リザーブは、そうしたことがすべて済んだあとに、まだ手つかずの履歴で取る測定です。

## 最後の部分を正直に保つ

四つに分けても、守らなければ役に立ちません。三つの習慣が、仕事のほとんどをしてくれます。

分け方は始める前に決め、書き残します。結果を見てから境界を動かせば、それも選択です。

何をもって合格とするかも、先に決めます。ルールがリザーブで届かなかったなら、正直な結果は「届かなかった」です。理由をつけて片づけたくなるはずですが、そこをこらえます。

リザーブを見るのは一度だけにします。見て、手直しして、また見れば、リザーブは作業用の部分がもう一つ増えただけになります。そうなると、判定に使えるものは何も残りません。

完全に守ったとしても、この分け方には限界があります。すべての部分に通ったルールは、過去に通ったのです。古い価格をどう並べても、まだ起きていない価格の代わりにはなりません。この分け方にできるのは、もっと控えめなことです。それでも価値があります。ルールを選んだのと同じ履歴に、そのルールの採点をさせない、ということです。
