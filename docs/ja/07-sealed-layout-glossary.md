# 取引ルールを確かめるための言葉：封をした分け方（学習、テスト、ホールド、リザーブ）

_履歴を役割の違う四つに分け、ルールを評価する履歴が、そのルールを選んだ履歴と決して同じにならないようにする考え方です。_

ある取引ルールが本物かと問うとき、次に必ず出てくる問いがあります。「どの履歴の上で本物なのか」です。封をした分け方は、何かを試す前に履歴を役割の違う四つに分けることで、この問いに答えます。

## 学習

探索が学ぶ履歴です。ルールはここで合わせ込まれるので、ここではルールはいつも良く見えます。学習で起きたことは、何ひとつ証拠になりません。

## テスト

探索が生んだルールの中から選ぶために使う履歴です。ルールを合わせ込んだ履歴ではありませんが、選択がなされた履歴であることに変わりはありません。多くのルールの中からテストで一番良いものを選んだ時点で、テストは勝者をひいき目に見始めます。

## ホールド

すべての選択がなされている間、取り分けておいた履歴です。生き残ったルールはここで、同じ期間を取引するより単純な方法と比べて評価されます。ホールドは最初の正直な読み取りですが、一度きりです。そこで見たものを理由に何かを変えれば、ホールドも選択に加わり始めます。

## リザーブ

ほかのすべてを決め終えたあと、最後に開ける最後の期間です。もう調整するものが何も残っていないときに、まだ見ていない部分です。ここで持ちこたえたルールは、どんな選択もなされなかった履歴の上で評価されたことになります。

## なぜ「封をした」のか

作業を始める前に各部分を決めておき、後の部分を先に見ないからです。履歴を二つにしか分けず、二つ目を何度も見れば、評価するはずの履歴の上でまた選んでいることになります。
