# 取引ルールを確かめるためのもう一つの言葉：決定的（同じ入力から同じ答え）

_取引の検証で「同じ入力から毎回同じ答えが出る」とはどういうことか、なぜ大切か、自分の道具をどう確かめるかを平易にまとめました。_

ある取引ルールが本物かどうかを問うとき、決まって出てくる言葉がもう一つあります。「決定的」です。平易な言葉で説明します。

## 意味

同じ入力から、毎回同じ答えが出るとき、そのテストは決定的だと言います。同じ価格、同じ設定、同じ版の道具からは、同じ取引、同じ点数、同じ判定が出ます。今日動かしても半年後に動かしても、自分のマシンでも他人のマシンでも同じです。

## なぜ大切か

再現できない結果は、確かめることのできない結果です。同じテストを二回動かして答えが食い違うなら、ルールが良くなったのは自分が何かを変えたからなのか、それとも道具がたまたま今回は違う答えを返しただけなのか、もう分かりません。ルールを確かめるときの比較はどれも、情報を持たない実行との比較も、より単純な取引方法との比較も、ルールが一度も見ていない履歴での比較も、「変わったのは自分が変えたものだけ」という前提の上に立っています。

他の人が見るときにも大切です。同僚や確認する人、あるいは後の自分が、同じ入力から同じ数字にたどり着けなければなりません。たどり着けないなら、その数字は証拠ではなく、ただの話です。

## 何がそれを壊すか

呼び出すたびに違う答えを返すものすべてです。テスト中に外部のサービスを呼ぶこと、結果と一緒に記録されない設定、知らないうちに修正される履歴、順序が決まっていない処理。どれも小さなもので十分に、二回の実行を食い違わせます。

## 自分の道具を確かめる方法

何も変えずに同じテストを二回動かし、結果を一行ずつ比べてください。次に、それぞれの結果が、どの価格、どの設定、どの版から生まれたのかを正確に示しているかを確かめてください。示していなければ、道具そのものが決定的であっても、後で同じ結果を出し直すことはできません。
