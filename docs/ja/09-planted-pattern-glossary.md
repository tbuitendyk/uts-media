# 取引ルールを確かめるための言葉：仕込んだパターン

_ルールを見つけたという探索を信じる前に、わざと隠したルールを見つけられるか確かめる。仕込んだパターンとは何か、どう使うかをまとめました。_

この一覧のこれまでの検査は、どれも「そのルールは本物か」を問うものでした。この検査は、それより前のことを問います。「そもそも探索は本物のルールを見つけられるのか」。

## 意味

仕込んだパターンとは、作り物の市場にわざと入れておくルールです。既知のパターンに従い、ノイズを混ぜた価格を作るので、始める前から正解がわかっています。そのうえで、本物の履歴に対するのとまったく同じように、その市場で探索全体を動かし、隠したものが見つかるかを確かめます。

## なぜ大切か

一度も失敗しない探索は、何の証明にもなりません。仕組みに欠陥があれば、存在しないルールを報告したり、存在するルールを見落としたりします。本物の履歴では、正解を誰も知らないので、どちらが起きているのか見分けられません。作り物の市場なら見分けられます。自分で仕込んだパターンを見つけられない探索は、仕込んでいないパターンを見つけたと言うとき、信頼に値しません。

## 使い方

パターンを仕込み、近道ではなく本物の処理の流れに通して、見つかることを確かめます。次に、同じ作り物の市場をかき混ぜてパターンを壊し、もう一度動かして、何も見つからないことを確かめます。両方が大切です。パターンを見つけることは探索が見えている証拠であり、かき混ぜた写しで何も出ないことは、ないものを見ていない証拠です。ソフトウェアが変わるたびに、この検査をやり直します。

## ほかの検査の中での位置

最初に来ます。どのルールを評価するよりも前です。まず測定器をテストし、それから測定値を信じます。そのあとに、「何もない」がどれだけ良く見えるか、ルールが一度も見ていない履歴、そして同じ期間を取引するより単純なやり方が続きます。
