# 測定値を信じる前に、まず測定器をテストする：既知のパターンを仕込む

_バックテストが本物の価格について言うことを信じる前に、答えのわかっている架空の市場で確かめます。その方法と、なぜ大事なのかを説明します。_

バックテストは測定器です。ルールと履歴を入れると、測定値が出てきます。テストで心配されるのは、たいていルールのほうです。合わせ込みすぎていないか、履歴は十分に長かったか、といった点です。もっと素朴な問いには、あまり注意が向きません。測定器そのものは、ちゃんと動いているのでしょうか。

もっともな問いです。テストのパイプラインはソフトウェアで、ソフトウェアには不具合があるからです。やっかいなのは、本物の履歴ではそれを見分けられないことです。パイプラインが「このルールは良い」と言ったとき、ルールが良いのか、パイプラインが間違っているのか、別の方法で確かめる手段がありません。正解を知らないのです。知らないからこそ、テストをしているのです。

ですから、本物の価格で信用する前に、答えのわかっている問題を解かせます。

## はかりと、重さのわかっているおもり

数字が出るというだけで、台所のはかりを信用する人はいません。重さのわかっているものを載せて、合っているかを見ます。次に、それを下ろして、ゼロを指すかを確かめます。この二つの確認は、別々の故障を見つけます。ゼロで固まったはかりは、二つ目には通り、一つ目で落ちます。何も載せていないのに重さを示すはかりは、二つ目で落ちます。

テストのパイプラインも、同じ二通りに故障します。一つは、見えていない場合です。データに本物の何かがあるのに、何も報告しません。もう一つは、ないものが見えている場合です。データには何もないのに、見つけたと報告します。取引で危ないのは二つ目です。「見つかった」というのは期待していた知らせで、良い知らせを二度確かめる人はめったにいないからです。

## パターンを仕込み、次にシャッフルする

バックテストにとっての「重さのわかっているおもり」は、わざとパターンを隠した架空の市場です。

まず、コイン投げで作った価格から始めます。一時間ごとに上がるか下がるかが決まり、ある一時間と次の一時間のあいだには何のつながりもありません。そこでは、どんなルールも何も見つけられません。見つけるものがないからです。次に、何かを仕込みます。たとえば、三回続けて上がったあとは、次の一時間が下がるより上がることのほうが多くなるようにします。パターンを選んだのはあなたです。どこにあるかも、どのくらいの強さにしたかも、わかっています。

この架空の市場を、パイプラインに通します。簡略化した写しでも、特別なテスト用モードでもありません。本物のパイプラインを、最初から最後まで通します。あとで本物の履歴を読むのと同じコードです。パイプラインは、仕込んだものを見つけなければなりません。

見つけられなければ、どこかが壊れています。それを知るのに、ここほど安上がりな場所はありません。よくある原因は地味なものです。シグナルが一時間ずれて並んでいる、途中の処理が黙って行を落としている、採点が違う列で計算されている、といったものです。どれも、本物のパターンを消してしまいます。本物の履歴であれば、「ここには何もなかった」と結論して終わっていたはずです。

ここまでがテストの半分です。残りの半分では、同じ架空の市場をシャッフルします。上げ下げは一つ残らずそのままで、順序だけが入れ替わります。パターンは消えています。これを同じパイプラインに通します。今度は、何も見つけてはなりません。

それでも「見つけた」と報告するなら、パイプラインにはないものが見えています。典型的な原因は、未来からの情報の漏れです。どこかで、ある一時間のための計算が、もっとあとの一時間をのぞけるようになっていたのです。こうした漏れがあると、ほとんど何でも良く見えます。ノイズでさえもです。実験室の言い方では、パターンを仕込んだ市場が陽性対照、シャッフルした市場が陰性対照です。結果を信じてよいのは、両方が正しく振る舞ったときだけです。

## 合格が意味すること

これで何が証明されるのかは、はっきりさせておきます。示されるのは、仕込んだのと同じ種類と強さのパターンを測定器が見つけられること、そしてパターンがないときには黙っていることです。本物の履歴で見つかった個々のルールについては、何も言いません。そうしたルールがこの先どうなるかについても、何も言いません。

この確認に意味があるかどうかは、二つの点で決まります。

仕込むパターンは弱くします。サイレンのように大きなパターンなら、半分壊れたパイプラインでも見つけてしまいます。本物のデータで見つかればと思っているものと、同じくらいの弱さにします。

合格は、それを得たコードに結びつけます。パイプラインを変えたら、確認はやり直しです。そうしないと、前回確かめてから一度分解して組み直したはかりを、そのまま信用することになります。
