# 거래 규칙을 검증하는 말: 봉인된 배치(학습, 테스트, 홀드, 리저브)

_이력을 역할이 다른 넷으로 나누어, 규칙을 평가하는 이력이 그 규칙을 고른 이력과 절대 같지 않게 하는 방법입니다._

어떤 거래 규칙이 진짜인지 물으면, 다음 질문은 언제나 같습니다. "어떤 이력 위에서 진짜인가?" 봉인된 배치는 무엇이든 시험하기 전에 이력을 역할이 다른 네 부분으로 나누어 이 질문에 답합니다.

## 학습

탐색이 배우는 이력입니다. 규칙은 여기서 맞춰지므로, 여기서는 규칙이 언제나 좋아 보입니다. 학습에서 일어난 일은 어떤 것도 증거가 되지 않습니다.

## 테스트

탐색이 만들어 낸 규칙들 가운데서 고르는 데 쓰는 이력입니다. 규칙을 맞춘 이력은 아니지만, 선택이 이루어진 이력이라는 점은 같습니다. 여러 규칙 가운데 테스트에서 가장 좋은 것을 고르는 순간, 테스트는 승자를 후하게 보기 시작합니다.

## 홀드

모든 선택이 이루어지는 동안 따로 떼어 둔 이력입니다. 살아남은 규칙은 여기서 같은 구간을 거래하는 더 단순한 방법들과 비교해 평가됩니다. 홀드는 첫 번째 정직한 측정이지만 단 한 번뿐입니다. 거기서 본 것 때문에 무언가를 바꾸면 홀드도 선택에 끼어들기 시작합니다.

## 리저브

다른 모든 결정을 마친 뒤 맨 마지막에 여는 마지막 구간입니다. 더 조정할 것이 남지 않았을 때 아직 보지 않은 부분입니다. 여기서 버틴 규칙은 어떤 선택도 이루어진 적 없는 이력 위에서 평가된 것입니다.

## 왜 "봉인된"인가

작업을 시작하기 전에 각 부분을 정해 두고, 뒤의 부분을 미리 보지 않기 때문입니다. 이력을 둘로만 나누고 두 번째 부분을 여러 번 들여다보면, 평가해야 할 이력 위에서 다시 고르게 됩니다.
