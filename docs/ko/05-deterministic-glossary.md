# 거래 규칙을 검증하는 또 하나의 말: 결정적(같은 입력, 같은 답)

_거래 연구에서 같은 입력이 언제나 같은 답을 낸다는 것이 무슨 뜻인지, 왜 중요한지, 자신의 도구를 어떻게 확인하는지 쉬운 말로 정리했습니다._

어떤 거래 규칙이 진짜인지 물을 때마다 빠지지 않고 나오는 말이 하나 더 있습니다. 바로 "결정적"입니다. 쉬운 말로 설명합니다.

## 뜻

같은 입력이 언제나 같은 답을 낼 때, 그 테스트를 결정적이라고 합니다. 같은 가격, 같은 설정, 같은 버전의 도구는 같은 거래, 같은 점수, 같은 판정을 냅니다. 오늘 돌리든 반년 뒤에 돌리든, 내 머신에서든 다른 사람의 머신에서든 마찬가지입니다.

## 왜 중요한가

다시 만들어 낼 수 없는 결과는 확인할 수 없는 결과입니다. 같은 테스트를 두 번 돌렸는데 답이 다르다면, 규칙이 나아진 것이 내가 무언가를 바꿨기 때문인지, 아니면 도구가 이번에는 그냥 다르게 답했기 때문인지 더는 알 수 없습니다. 규칙을 검증할 때의 모든 비교, 즉 정보 없는 실행과의 비교, 더 단순한 거래 방법과의 비교, 규칙이 한 번도 보지 못한 이력에서의 비교는 모두 "바뀐 것은 내가 바꾼 것뿐"이라는 전제 위에 서 있습니다.

다른 사람이 볼 때도 중요합니다. 동료나 검토하는 사람, 혹은 나중의 나 자신이 같은 입력으로 같은 숫자에 도달할 수 있어야 합니다. 그렇지 못하다면 그 숫자는 증거가 아니라 이야기일 뿐입니다.

## 무엇이 그것을 깨뜨리나

호출할 때마다 다르게 답하는 모든 것입니다. 테스트 도중 외부 서비스를 부르는 것, 결과와 함께 기록되지 않는 설정, 모르는 사이에 고쳐지는 이력, 순서가 정해지지 않은 단계. 어느 것도 크지 않아도 두 번의 실행을 서로 다르게 만들기에 충분합니다.

## 자신의 도구를 확인하는 방법

아무것도 바꾸지 않고 같은 테스트를 두 번 돌린 뒤, 결과를 한 줄씩 비교해 보세요. 그다음 각 결과가 어떤 가격, 어떤 설정, 어떤 버전에서 나왔는지 정확히 말해 주는지 확인하세요. 말해 주지 않는다면, 도구 자체가 결정적이라도 나중에 같은 결과를 다시 낼 수 없습니다.
